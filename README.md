# Dolos

浏览器里的 3D 酒馆 + 桌游。走进大厅、挑一张桌子坐下、选今天打什么，
剩下的位置由 AI 补位。

**线上 demo**：https://parthenon-labs.github.io/dolos/

> 虚拟筹码，不可充值提现。

---

## 现在能玩到什么

- **一座两层酒馆**，可自由走动、上下楼、靠近空位坐下。全程零美术资源，
  几何体 + 光照 + 后处理撑起来的
- **坐下之后选游戏**。同一张桌子，今天打扑克明天打斗地主。三个都做完了：

| | 人数 | 规则完整度 |
|---|---|---|
| **德州扑克** | 2–6 | 盲注、四条街、加注规则、all-in、边池、摊牌 |
| **斗地主** | 3 | 叫分抢地主、十四种牌型、炸弹翻倍、春天/反春天 |
| **卡坦岛** | 3–4 | 开局蛇形摆放、产出、强盗与弃牌、五种发展卡、最长路/最大军、港口汇率、十分获胜 |

- 每个游戏都有一套启发式 bot，各有不同的性格参数，
  一桌人不会像同一个人在打

## 跑起来

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # 三个游戏的规则引擎全部检查
npm run check:ddz  # 也可以单独跑某一个
npm run check:catan
npm run build
```

这个项目里几乎每个难缠的 bug 都长一个样：代码看着是对的、测试是绿的、也不报错。

## 这个项目里值得看的部分

### 牌力评估不用查表

`src/poker/evaluate.ts` 穷举 C(7,5)=21 种五张组合打分取最大。
查表法快几十倍，但一张十几万项的表**没法用眼睛验证**，
而这是决定谁拿钱的代码。21 次组合每手不到 10 微秒，瓶颈根本不在这。

### 三个游戏共用一套"选择面板 + 2D 层"

落座之后先出一块选择面板（`src/games/registry.ts`），选完了才由对应游戏的
2D 层接管。牌桌一直是**盖在 3D 上的一层**而不是替换掉它 ——
所以换游戏、离席都只是换这一层，酒馆一直在背后渲染。

**人数和椅子数是两回事**：斗地主永远三个人，六人桌开斗地主就坐三个。
桌子本身不知道在打什么。

### 兜住分池 bug 的是不变量，不是用例

用例只能覆盖你想到的情况。真正的网是两条：

- **筹码守恒** —— 一手牌前后所有人筹码总和必须精确相等。分错钱几乎必然破坏它
- **边池样本量** —— all-in 在均匀随机对局里出现得不够密，所以刻意用参差不齐的
  起始筹码把它逼出来。现在 4000 手随机牌局里有 2698 手产生边池，
  这个数字掉下去就说明覆盖没了

`settle()` 里的守恒断言是**抛错而不是记日志**：分池写错时它立刻炸，
而不是等玩家发现自己少了钱。

三个游戏各有一条同位置的守恒律，都是抛错：
德州是**筹码守恒**，斗地主是**积分守恒**（三家进出加起来精确为零），
卡坦是**资源守恒**（每种资源永远 19 张，银行加所有人手上）。
最后这条在开发时立刻抓到了一个 bug：盖东西花掉的资源没还给银行，
一局下来 95 张只剩 31 张，银行发空、产出停摆 ——
**场面上没有任何报错，只是"大家都很穷"**。

### 隐藏信息在投影层就切干净

`project(state, seat)` 是发给玩家的唯一出口，别人的牌在这里就被抹掉了，
不是靠前端不渲染。一旦漏，客户端改个变量就能看穿全场。

三个游戏的隐藏信息形状还不一样，卡坦那个尤其容易漏：
**别人手上有几张资源是公开的，具体是哪几张不是**。
这种"部分公开"不能整个字段抹掉，得压成一个数字 ——
前端顺手一个 `player.hand` 就漏了。所以照样只走 project()。

### 界面不判断规则，只把 legal() 翻译成高亮

卡坦的规则面比牌类游戏宽得多：距离规则、路要连着、港口汇率、
发展卡这回合能不能用……如果界面自己判断哪里能点，
它和引擎迟早会判得不一样。

所以引擎导出 `legal(state, seat)` 列出此刻的全部合法动作，
**界面和 bot 吃同一份**：按钮灰不灰、棋盘上哪些路口亮起来，
全部从这个列表推出来。

### 光源预算

大厅里有四十多盏灯，全开是 9.7 FPS。
`src/scene/LightBudget.tsx` 只让最近的 N 盏可见，且**可见数量恒定** ——
数量变化会触发 three.js 重编译着色器，比多点几盏灯贵得多。
改完 70.8 FPS。

## 状态

**这是个 demo，不是产品。** 对局完全跑在浏览器里 ——
也就是说牌堆和棋盘都在客户端内存里，联机对战之前它只能一个人打 bot。

三个游戏都能从头打到尾，但有两处**明确没做**：

- **卡坦没有玩家之间的交易**，只有和银行/港口换。
  和 bot 讨价还价这件事，要做得不像摆设需要的东西比规则本身还多
- **港口的位置不是官方那套**。官方是印死在板子上的，
  而这里的盘面每局重开都不一样。数量、种类、二换一/三换一的配比按官方，
  位置是沿海岸等距取的

已经做完和还没做的，以及一路上踩过的坑（含好几个"测试用例本身写错了"的例子），
都写在 [NOTES.md](NOTES.md)。
